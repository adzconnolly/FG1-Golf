Upload index.html to the root of your FG1-Golf GitHub repository, replacing the existing index.html.

Scoring:
- Stableford from Playing Handicap + Stroke Index
- Fairway hit on par 4/5: +1 FG1
- GIR: +1 FG1
- Par 5 green in 2: +2 FG1
- 1 putt: +1 FG1
- 3+ putts: -1 FG1
- Each lost ball: -1 FG1
- Total = Stableford + FG1

This version is self-contained and does not require a manifest or service worker to load.
