FG1 Golf MVP

Files:
- index.html
- manifest.webmanifest
- sw.js

What works:
- Up to 4 players
- Playing Handicap input
- Handicap strokes allocated by Stroke Index, including handicaps above 18
- Gross score
- Stableford calculation
- Fairway +1 on par 4/5
- GIR +1
- Par 5 green in 2 = +2 instead of GIR +1
- 1 putt +1
- 3+ putts -1
- Each lost ball = -1 FG1 point (e.g. 2 lost balls = -2)
- FG1 Total = Stableford + FG1
- Live leaderboard
- 18-hole scorecard and editing
- Result screen
- Local/offline storage on device after first load

To use on iPhone:
1. Host these files on an HTTPS static website.
2. Open the URL in Safari.
3. Share > Add to Home Screen.
4. Turn on “Open as Web App” if shown.
